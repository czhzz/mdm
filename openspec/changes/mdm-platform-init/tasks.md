# 开发计划（8 周 / 80 人天，按 2 人团队：后端 + 前端并行）

> 周期：8 周（含首期演示与 1.0.0 发布）。里程碑见文末"里程碑安排"。
> 每任务标注预估工时（人天）。

## 第 1 周：工程底座与模型管理基础（10 人天）

- [x] 1.1 创建 `ruoyi-mdm` Maven 模块骨架（与 ruoyi-system 平级，pom.xml + model/coderule/standard/maintenance/quality/distribution 六个子包），在 ruoyi-admin/pom.xml 引入依赖（工时：1.5 人天）
- [x] 1.2 编写 `sql/mdm/init.sql`：mdm 元数据表（object/attribute/category 第一期 + 种子字典与菜单数据）（工时：2.5 人天）
- [x] 1.3 前端新增 mdm 菜单路由与页面骨架（空页面 + 路由注册 + 侧边栏菜单）（工时：2 人天）
- [x] 2.1 后端：数据对象与分类 CRUD 接口（mdm_object、mdm_category），对象编码全局唯一校验（工时：2 人天）
- [x] 2.2 后端：属性定义接口（mdm_attribute），对象内属性编码唯一校验（工时：2 人天）

## 第 2 周：模型发布与动态维护（10 人天）

- [ ] 2.3 后端：模型发布——校验（至少一个属性、编码白名单）后动态建表 `mdm_data_<obj_code>`（通用列 + 属性列 + 唯一索引），对象状态置为已发布（工时：3 人天）
- [ ] 2.4 后端：对象/属性停用与删除规则（已发布对象不可删，仅可停用）（工时：1 人天）
- [ ] 2.5 后端：模型元数据查询接口（供前端动态渲染维护页）（工时：1 人天）
- [ ] 2.6 前端：模型管理页面（对象列表 + 分类树 + 属性配置 + 发布/停用操作）（工时：2.5 人天）
- [ ] 3.1 后端：动态 CRUD——按对象元数据生成增删改查（参数化动态 SQL，对象编码白名单校验）（工时：2.5 人天）

## 第 3 周：维护完善与编码规则（10 人天）

- [ ] 3.2 后端：服务端校验（必填/唯一/值域，见 5.2 值域校验）（工时：2 人天）
- [ ] 3.3 后端：生命周期状态机（草稿/已生效/已停用）与状态流转接口（工时：1.5 人天）
- [ ] 3.4 后端：组合查询（关键字/状态/属性值）与详情接口（含操作审计记录）（工时：1.5 人天）
- [ ] 3.5 前端：动态维护页面（按元数据渲染表单、列表、详情、状态操作）（工时：2.5 人天）
- [ ] 4.1 后端：编码方案配置接口（mdm_code_rule 分段配置：常量/日期/流水/属性值 + 示例预览 + 同对象唯一）（工时：2.5 人天）

## 第 4 周：编码生成与数据标准（10 人天）

- [ ] 4.2 后端：编码生成器——Redis INCR 流水号（周期重置：不重置/日/月/年 + 溢出处理）+ 业务表唯一索引兜底（工时：2.5 人天）
- [ ] 4.3 后端：新增数据时自动生成编码并回填（工时：1 人天）
- [ ] 4.4 前端：编码方案配置页面（分段编辑器 + 预览）（工时：1.5 人天）
- [ ] 5.1 后端：标准字典管理接口（mdm_dict 类型/项，类型内编码唯一）（工时：2 人天）
- [ ] 5.2 后端：属性绑定值域（标准字典/数值范围/枚举）+ 录入与导入时的值域校验（工时：1.5 人天）
- [ ] 5.3 前端：标准字典管理页面 + 属性配置支持绑定字典（工时：1.5 人天）

## 第 5 周：数据质量与审核流程（10 人天）

- [ ] 6.1 后端：校验规则配置接口（必填/格式正则/值域/唯一，对象级与属性级，可启停）（工时：2 人天）
- [ ] 6.2 后端：校验引擎——录入与批量导入时执行规则并反馈违规信息（工时：2 人天）
- [ ] 6.3 后端：重复检测（查重字段配置 + 分组结果 + 无重复提示）（工时：1.5 人天）
- [ ] 6.4 后端：质量台账（问题登记：校验失败/重复/缺失；处理：忽略/已处理，记录处理人与时间）（工时：1.5 人天）
- [ ] 6.5 前端：校验规则配置 + 重复检测操作 + 质量台账页面（工时：1.5 人天）
- [ ] 7.1 后端：审核流程配置（启用/禁用 + 审核角色）（工时：1.5 人天）

## 第 6 周：审核完善与首期演示（10 人天）

- [ ] 7.2 后端：审核任务——提交（变更前后快照 mdm_audit_task）、审核通过/驳回、驳回原因保存、状态回写（工时：2.5 人天）
- [ ] 7.3 后端：已生效数据修改走待审核版本（不覆盖生效数据）（工时：1.5 人天）
- [ ] 7.4 前端：提交审核入口 + 我的待办/审核页面（工时：2 人天）
- [ ] 7.5 首期演示：准备演示数据与脚本，完成全链路演示（模型发布 → 编码生成 → 数据维护 → 审核 → 质量 → 分发推送）（工时：3 人天）
- [ ] 7.6 收集演示反馈并记录调整项（工时：1 人天）

## 第 7 周：数据分发与集成（10 人天）

- [ ] 8.1 后端：应用凭证管理（mdm_app 注册订阅方，生成 appid/secret）（工时：1 人天）
- [ ] 8.2 后端：分发配置接口（订阅方/对象/触发时机）+ 内嵌分发器（异步推送 + mdm_distribution_record 记录）（工时：2.5 人天）
- [ ] 8.3 后端：分发记录查询 + 失败重推（工时：1 人天）
- [ ] 8.4 后端：Excel 模板下载 + 批量导入（模板列校验 + 逐行校验 + 失败行错误反馈）（工时：2 人天）
- [ ] 8.5 后端：Excel 导出（按查询条件）（工时：1 人天）
- [ ] 8.6 后端：对外接口——主数据查询接口 + 变更推送确认接口（appid/secret 凭证鉴权，无效凭证返回 401）（工时：1.5 人天）
- [ ] 8.7 前端：分发配置/记录页面 + 导入导出入口（工时：1 人天）

## 版本 1.1.0 展望（1.0.0 发布后规划）

- 主数据对象关系建模（关联/引用，spec 已预留）
- 数据质量大屏与报表（质量趋势、对象健康度）
- 多级/会签审核流程（视需求引入 Flowable）
- RabbitMQ 异步分发与订阅方自助接入（决策五扩展点落地）
- 主数据血缘追踪（数据来源与去向可视化）
- 主数据对象模板库（客户/供应商/物料等标准模板开箱即用）
- 迁移 RuoYi-Cloud 微服务架构（mdm 模块独立部署）的评估
