# mdm-1.1.0

主数据管理平台 1.1.0 —— 对象关系建模、审核升级、分发增强、质量大屏、血缘追踪、模板库、微服务评估

## 版本

1.1.0（基于 1.0.0 增量升级）

## 轨道

### 轨一：业务功能（6 项）

| 模块 | 说明 | 新增依赖 |
|------|------|----------|
| 对象关系建模 | 方案 B：引用属性 + `mdm_relation` 关系表，支持 1:1/1:N/N:M 与级联规则 | 无 |
| 审核流程升级 | 方案 B：Flowable 6.x 深度集成，BPMN 流程设计器，会签/转办/退回 | Flowable 6.x |
| RabbitMQ 分发 | 方案 A：HTTP 推送 + MQ 双通道共存，保留线程池 | RabbitMQ (Spring AMQP) |
| 数据质量大屏 | 方案 A：ECharts 单页大屏（质量趋势、对象健康度、规则命中、问题列表） | 无（前端 ECharts 已有） |
| 血缘追踪 | 方案 A：基于审计 + 分发记录，数据详情页血缘 Tab，ECharts 关系图 | 无 |
| 对象模板库 | 5 个预置模板（客户/供应商/物料/组织/人员），一键创建完整对象配置 | 无 |

### 轨二：独立评估（1 项）

| 模块 | 说明 |
|------|------|
| RuoYi-Cloud 微服务评估 | 评估报告：迁移成本、收益、风险、建议时间线，不写代码 |

## 新增依赖

- **Flowable 6.x**：Spring Boot 2.5.15 兼容版本，流程引擎 + BPMN 设计器
- **RabbitMQ**：Spring AMQP 集成，消息队列分发通道
- 前端组件：bpmn-js（流程设计器），ECharts（大屏）—— 后者若依已有

## 不变量

- 不改动若依底座（sys_* 表、RBAC、认证授权）
- 不改动 1.0.0 核心 MDM 元数据表结构（仅扩展字段）
- 废弃 `mdm_audit_flow` / `mdm_audit_task` 表（Flowable 替换）
- HTTP 分发通道保留，MQ 为新增选项
