# 主数据管理平台 需求总览（1.0.0）

## 定位与目标

面向企业的主数据（Master Data）统一管理平台，承载客户/供应商等核心基础数据的标准、维护、质量与分发。基于若依（RuoYi）底座构建，为业务系统提供**唯一权威（Single Source of Truth）**的主数据服务。

## 六大功能能力

| 能力 | 说明 | 关键对象 |
|------|------|----------|
| 模型管理 | 对象/分类/属性建模、发布动态建表、版本化演进 | `mdm_object` / `mdm_attribute` / `mdm_category` |
| 编码规则 | 分段编码（常量/日期/流水/属性值）、周期重置、Redis 原子流水 | `mdm_code_rule` / `mdm_code_rule_segment` |
| 数据标准 | 标准字典复用若依字典，属性绑定值域（枚举/字典/范围） | `sys_dict_*` |
| 维护审核 | 动态维护页、生命周期状态机、审核流程（前后快照、通过/驳回） | `mdm_audit_task` / `mdm_audit_flow` |
| 数据质量 | 校验规则、重复检测、质量台账 | `mdm_quality_rule` / `mdm_quality_issue` |
| 分发集成 | 应用凭证、分发配置、异步推送、失败重推、Excel 导入导出、对外查询 API | `mdm_app` / `mdm_distribution` / `mdm_distribution_record` |

## 角色与权限

- **管理员**：模型/编码/标准/维护/审核/质量/分发全部操作（菜单 2000-2035，`*:*:*`）。
- **业务维护**：数据维护、提交审核（`mdm:maintenance:*`）。
- **审核人员**：审核任务通过/驳回（`mdm:maintenance:edit`）。
- **订阅方系统**：机器对机器，应用凭证（appid/secret + 签名）访问对外接口，不走用户登录。

## 核心业务流

```
模型发布 ──> 编码规则 ──> 数据维护 ──> 审核（可选）──> 质量监控 ──> 分发推送 ──> 订阅方系统
   ↑                                                          │
   └──────────────┬──────────────────────────────────────────┘
             示例对象：客户 / 供应商
```

1. 管理员建模并发布 → 自动建业务表、对象生效。
2. 业务人员维护数据；编码按规则自动生成回填。
3. 启用审核的对象：新增/修改先入待审核，审核通过才落库生效（驳回不覆盖）。
4. 质量规则在录入/导入时校验，违规进入质量台账；查重发现重复。
5. 数据变更后按分发配置异步推送给订阅方，失败可查询重推。
6. 订阅方通过对外接口查询主数据。

## 非功能需求

- **数据安全**：动态 SQL 全参数化 + 表/列白名单校验；对外接口签名鉴权 + 时间窗口防重放；无效凭证 HTTP 401。
- **可用性**：分发异步化，订阅方不可用不影响主流程；失败记录可重推。
- **可运维**：初始化/种子脚本幂等，容器化一键部署，`doc/operations.md` 提供备份与排查手册。
- **可回滚**：mdm 与若依完全隔离，停用 mdm 不影响若依原功能（`doc/release-checklist.md`）。

## 约束与演进（1.1.0 展望）

- 本期仅允许已发布对象「新增可空/带默认值属性」演进；破坏性变更需新建对象版本。
- 分发为内嵌异步推送；订阅方规模扩大后引入 RabbitMQ（设计决策五扩展点）。
- 对象关系建模 / 质量大屏 / 多级会签留待 1.1.0。
