# 发布说明 RELEASES

## v1.0.0（2026-08）

主数据管理平台 1.0.0 发布。基于若依 3.9.x 底座，六大能力域全部落地，可作为主数据唯一权威源接入业务系统。

### 新增能力

- **模型管理**：对象/分类/属性动态建模，发布自动建表；版本化演进（仅新增可空/带默认值属性）。
- **编码规则**：分段编码（常量/日期/流水/属性值），Redis 原子流水按日/月/年周期重置，业务表唯一索引兜底。
- **数据标准**：数据类型、枚举/字典/数值范围值域绑定，录入与导入时校验。
- **数据维护与审核**：动态维护页、生命周期状态机（草稿/生效/停用）、审核流程（变更前后快照、通过/驳回带原因、已生效数据修改不覆盖）。
- **数据质量**：校验规则（必填/正则）、重复检测分组、质量台账（处理/忽略，记录处理人时间）。
- **数据分发与集成**：应用凭证（appid/secret + HMAC 签名鉴权）、分发配置（订阅方/对象/触发时机）、内嵌异步分发器、失败重推、Excel 模板/导入/导出。
- **对外接口**：`GET /open/mdm/data` 主数据查询、`POST /open/mdm/distribution/confirm` 推送确认，无效凭证返回 401。

### 示例落地

- 示例对象：**客户**（启用审核）、**供应商**（直接维护），均含编码方案与完整演示链路轨迹。

### 破坏性变更 / 兼容性

- 新增 `mdm_*` 表与菜单（2000-2035），`sys_*` 若依表未改动，停用 mdm 不影响若依原功能。
- 数据库初始化/种子脚本幂等，可重复执行。

### 已知限制（1.1.0 规划）

- 分发为内嵌异步推送（固定线程池），订阅方规模扩大后引入 RabbitMQ。
- 对象关系建模、质量大屏、多级会签审核、移动端待办待 1.1.0。
